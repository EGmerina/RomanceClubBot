# 🎮 Case Club Bot — запуск на Mac

## 1. Откройте Terminal

Нажмите:

**⌘ Command + Space**

Введите:

```text
Terminal
```

и нажмите **Enter**.

---

## 2. Установите Python

Введите:

```bash
python3 --version
```

Если появилась версия, например:

```text
Python 3.12.5
```

→ переходите к шагу 3.

Если написано `command not found`, скачайте Python:

[Скачать Python для Mac](https://www.python.org/downloads/macos/?utm_source=chatgpt.com)

Установите его и **перезапустите Terminal**.

---

## 3. Распакуйте zip архив и откройте папку с проектом

откройте папку RomanceClubBot в Terminal.

В Finder найдите папку проекта.
Нажмите на неё правой кнопкой мыши и выберите пункт вроде:

Новый терминал в папке

или:

New Terminal at Folder

После этого Terminal откроется сразу в нужной папке.
## 4. Создайте виртуальное окружение

В папке проекта выполните:

```bash
python3 -m venv .venv
```

---

## 5. Запустите бота

Сначала:

```bash
chmod +x run_bot.sh
```

Затем:

```bash
./run.sh
```

**Готово! 🤖**

При первом запуске программа сама установит необходимые библиотеки. Это может занять несколько минут.

---

## 🔄 В следующий раз

Больше ничего устанавливать не нужно.

Откройте Terminal, перейдите в папку проекта:

```bash
cd ~/Desktop/НАЗВАНИЕ_ПРОЕКТА
```

и запустите:

```bash
./run_bot.sh
```

---

## 🛑 Чтобы остановить бота

В Terminal нажмите:

**Ctrl + C**

---

### ⚠️ Если Mac не разрешает запустить `run.sh`

Выполните:

```bash
bash run.sh
```

Если появится ошибка — отправьте её разработчику целиком.
